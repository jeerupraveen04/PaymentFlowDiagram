Key Rules / Decision Points

  • Use PG-specific timeout duration or Cancel API.
  • If neither exists, use 7-day default timeout.
  • Block payment when an open Pending / Processing transaction exists.
  • Handle deposit, remaining amount and additional sale flows.
  • Send Pending Action Email for configured cases.
  • Use Rescue Service for all PGs.
  • Validate payment order before confirming transaction.
