# Taste

## Code changes & workflow
- Prefers changes to existing content to be purely additive: leave what already exists completely untouched and add new material (e.g. a new section below the existing one), rather than editing, refactoring, or restructuring what already works. Confidence: 0.8

## Design & diagrams
- Wants new sections to carry a clear heading and stay visually consistent with the existing page's design. Confidence: 0.65
- Prefers flow diagrams/flowcharts where each node type (cron job, backend/service, payment gateway, database, email, user, decision, end, etc.) gets its own distinct color/styling so the types are visually distinguishable at a glance. Confidence: 0.65
